# Guia del agente: usar el MCP para construir y ejecutar jobs de Talend

Esta guia explica como usar el servidor MCP contra un Talend Studio abierto. Si lo que quieres
hacer es cambiar el codigo del repo, empieza por [AGENTS.md](../AGENTS.md).

Si es tu primera vez, lee primero [AGENTE-EXTERNO.md](AGENTE-EXTERNO.md): son ocho llamadas y un ejemplo que
pasa en Talend. El contenido de esta guia esta separado por tema para que se pueda leer solo la parte necesaria.
